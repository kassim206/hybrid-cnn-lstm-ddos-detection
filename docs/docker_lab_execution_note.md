# Docker/Kali/hping3 Lab Execution Note

This repository includes supplementary Docker/Kali/hping3 configuration files for a controlled local laboratory setup.

The configuration includes:

- `docker/docker-compose-lab.yml`
- `docker/kali/Dockerfile`
- `docs/network_topology.md`
- `scripts/traffic_generation/hping3_connectivity_test.sh`

The main machine learning experiments and reported model results were produced using the CIC-DDoS2019 dataset and Python experiment scripts.

The Docker/Kali/hping3 setup is provided as supplementary reproducibility material. It requires Docker Desktop or another Docker-compatible runtime to execute. If Docker is not installed, the lab configuration cannot be executed locally.

No public-network traffic generation is included or required.
