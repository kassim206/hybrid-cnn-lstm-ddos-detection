## Thesis Title

Hybrid Machine Learning-Based Real-Time DDoS Detection and Mitigation for Web Applications

## Overview

This project implements a hybrid CNN-LSTM machine learning framework for detecting and mitigating DDoS attacks in real time. The system uses the CIC-DDoS2019 dataset, traditional machine learning baselines, and a deep learning model for comparative evaluation.

## Main Components

- Dataset preprocessing
- Feature selection
- Random Forest baseline model
- SVM baseline model
- Hybrid CNN-LSTM model
- Model evaluation
- Real-time mitigation prototype
