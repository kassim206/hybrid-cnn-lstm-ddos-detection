# Thesis Summary

## Title

Hybrid Machine Learning-Based Real-Time DDoS Detection and Mitigation for Web Applications

## Author

Mohammed Kassim Cherukodan

## University

Vytautas Magnus University  
Faculty of Informatics  
Applied Informatics  
Master Thesis, 2026

## Supervisor

Prof. Dr. Tomas Krilavičius

## Summary

This thesis proposes a hybrid CNN-LSTM machine learning framework for real-time DDoS detection and mitigation in web applications.

The CNN component is used to extract spatial traffic patterns, while the LSTM component captures temporal dependencies in network flow sequences. The proposed model is compared with traditional machine learning baselines, including Random Forest and Support Vector Machine.

The system is evaluated using standard classification metrics, inference latency, and resource overhead analysis. A proof-of-concept real-time mitigation module is also included to demonstrate dynamic rate limiting and traffic filtering based on model prediction confidence.

## Main Contributions

- CIC-DDoS2019 dataset preprocessing workflow
- Feature selection using correlation analysis and Random Forest importance
- Random Forest and SVM baseline models
- Hybrid CNN-LSTM detection model
- Real-time DDoS mitigation prototype
- Thesis figures and visualization scripts
- Professional GitHub repository for research reproducibility
